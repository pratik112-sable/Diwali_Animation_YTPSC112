# Diwali Animation

Play the animation in your browser: https://pratik112-sable.github.io/Diwali_Animation_YTPSC112/

The site is built from [Diwali.py](./Diwali.py) with pygbag and automatically deployed to GitHub Pages whenever changes are pushed to `main`.

For local desktop play, install Pygame and run `python Diwali.py`.

## Controls

- Click the scene to launch a firework.
- Press `Space` for a grand finale.
- Press `A` to toggle automatic fireworks.
- Press `P` to pause, `F` to toggle fullscreen, and `H` to hide the help text.
- Press `S` to save a snapshot when running the desktop version.
