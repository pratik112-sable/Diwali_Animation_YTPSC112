# Diwali Animation

Play the browser version: https://pratik112-sable.github.io/Diwali_Animation_YTPSC112/

The browser build is generated from [Diwali.py](./Diwali.py) with pygbag and published on GitHub Pages.

For local desktop play, install Pygame and run `python Diwali.py`.

Controls: click to launch a firework, `Space` for the grand finale, `A` to toggle autoplay, `P` to pause, `F` for fullscreen, and `H` to hide controls. Press `S` to save a snapshot in the desktop version.
