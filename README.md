# Diwali Animation

Play the browser version: https://pratik112-sable.github.io/Diwali_Animation_YTPSC112/

The browser build is generated from [Diwali.py](./Diwali.py) with pygbag and published on GitHub Pages.

For local desktop play, install Pygame and run `python Diwali.py`.

Controls: click to launch a firework, `Space` for the grand finale, `A` to toggle autoplay, `P` to pause, `F` for fullscreen, and `H` to hide controls. Press `S` to save a snapshot in the desktop version.

🪔 DIWALI • Festival of Light
An interactive, procedurally generated Diwali celebration built entirely with Python and Pygame.
Zero external assets required! All artwork—including the glowing diyas, intricate rangoli mandala, floating sky lanterns, city skyline, festive string lights, and dynamic fireworks—is generated mathematically in code with no image, font, or audio downloads needed.
✨ Features
100% Procedural Artwork: Every visual element is drawn in real-time using mathematical curves, polygons, and custom additive surface blending for lighting and glow effects.
Cinematic Intro: Smooth, staggered fade-in transitions introduce the starry night sky, festive lights, floating lanterns, rangoli floor art, flickering diyas, and typography in sequence.
Interactive Fireworks System: Features 4 distinct firework styles (Peony, Ring, Willow, and parametric Heart shapes) with physics-based drag, gravity, and glowing spark trails.
Personalizable Greeting: Pass your name via the command line to sign the greeting card with a custom "With love, [Your Name]" message.
Built-in Snapshot Studio: Capture high-resolution PNG screenshots of the scene at any moment with a single keypress.
Responsive Viewport: Supports window resizing and fullscreen mode with automatic aspect-ratio letterboxing.
Performance Scaling: Includes high and low quality modes to adjust particle caps and glow calculations for smoother playback on older hardware.
